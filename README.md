# Insurance Analytics Dashboard

## Project Overview

This Power BI dashboard provides insights into insurance policies, premium amounts, coverage amounts, claim amounts, and customer demographics.

## Features

- Premium Amount Analysis
- Coverage Amount Analysis
- Claim Amount Analysis
- Policy Type Insights
- Claim Status Analysis
- Age Group Analysis
- Interactive Filters

## Tools Used

- Power BI
- Excel
- DAX

## Dashboard Preview



## Key Insights

- Travel policies generated the highest premium amount.
- Adults accounted for the largest claim amount.
- Claims are categorized as Rejected, Settled, and Pending.
